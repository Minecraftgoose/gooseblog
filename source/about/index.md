我是 **Goose**（Minecraft_goose）。写点网页开发、工具折腾的东西，偶尔写点有用的。

这个站原来跑在 Cloudflare Pages + Pages Functions + Supabase 上：前端是个 SPA，文章、友链、公告全靠 Worker 现查数据库往回吐 JSON。

现在它变成了纯静态站：

- 生成：**Hexo**
- 主题：**hexo-theme-redefine**
- 部署：Cloudflare Pages（域名不变）
- 后端：**已删除**，文章就是仓库里的 Markdown

资源一件没丢：背景图、头像、Logo、钉钉进步体、prism，全是原来那几个文件。
原来那些好用的小东西也留下了：首页发文热力图、右下角复制链接 / 生成海报、链接卡片、侧栏那 81 句《流浪地球》台词。

> 旧文章请用 `npm run export:goose` 从 Supabase 一键导进来（见 README）。
