# 怎么查网站有没有被收录？

想知道网站有没有被搜索引擎收录，最简单的方法只需要一步。

## 核心方法：site 命令

打开 Bing 搜索（Google、百度也行），在搜索框里输入：

```
site:你的域名
```

举例，如果网站是 `starblog.totalh.net`，就输入：

```
site:starblog.totalh.net
```

然后按回车。

## 怎么看结果

- 搜索结果里出现了你的网站链接 → 恭喜，已经被收录了。
- 显示「没有找到任何结果」 → 暂时还没被收录。

## 查单个页面

想查某个具体页面有没有被收录，就在域名后面加上路径，例如：

```
site:starblog.totalh.net/hello
```

## 小提示

- 新网站提交给搜索引擎后，通常需要几天到几周才会被收录，这段时间耐心等一等。
- 如果等了比较久还没被收录，可以去 Bing 站长工具（或 Google Search Console）提交站点地图（sitemap），帮助搜索引擎更快发现你的网站。

就这么简单，不需要任何代码，也不需要装插件，记住 `site:你的域名` 这一招就够了。
