# Markdown 入门教程：从零开始写出一篇漂亮的博客文章

> 转载自：[MD入门教程 – Star Blog](https://starblog.totalh.net/wp59/archives/4/md%E5%85%A5%E9%97%A8%E6%95%99%E7%A8%8B)

如果你刚开始写博客，一定被一个问题困扰过：**排版太麻烦了**。

加粗要找按钮，标题要选字号，贴代码更是灾难现场——缩进全乱，颜色全丢。直到我遇见了 **Markdown**，一切都变了。它让我只用纯文本就能写出结构清晰、格式美观的文章。这篇教程，就是写给完全没接触过 Markdown 的你。

---

## 什么是 Markdown？

Markdown 是一种**轻量级标记语言**。说人话就是：你用普通文字加几个简单符号，它就能自动变成标题、加粗、列表、链接。全程键盘搞定，手不用离开主键盘区。

它由 John Gruber 于 2004 年发明，核心理念是：**让写作者专注于内容本身，而不是排版**。如今 GitHub、Typora、Obsidian、Notion、WordPress 等主流平台全部支持 Markdown，它已经成为技术写作的事实标准。

---

## 为什么要学 Markdown？

三个理由，值得你花半小时学会它：

**1. 写作效率翻倍**

不用停下打字的手去点加粗按钮，直接在文字两边加两个星号就行。思路不断，心流不停。

**2. 一次学会，到处能用**

GitHub 写 README 用 Markdown，论坛发帖用 Markdown，笔记软件记东西还是 Markdown。学一次，受益终身。

**3. 格式干净，永不翻车**

Word 里粘贴后字体大小不一致、格式莫名错乱……这些在 Markdown 里永远不会发生。你写的是什么，出来就是什么。

## 基础语法详解

下面逐一讲解最常用的语法，每个都配有**写法**和**效果说明**。

### 一、标题

标题用 `#` 加空格表示。一个井号是一级标题，两个是二级，以此类推，最多支持六级。

> **最佳实践**：一篇文章建议只用一个 `#`（一级标题），即文章标题本身。`##` 用于主要章节，`###` 用于小节，形成清晰的层级结构。

写法：

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

---

### 二、加粗与斜体

这是日常写作中最常用的两个格式：

| 效果 | 写法 | 规则 |
|---|---|---|
| **加粗** | `**加粗**` | 文字两边各加两个星号 |
| *斜体* | `*斜体*` | 文字两边各加一个星号 |
| ***加粗斜体*** | `***加粗斜体***` | 文字两边各加三个星号 |

**注意**：星号和文字之间**不要有空格**。写成 `* 斜体 *` 会导致部分编辑器无法识别。

---

### 三、删除线

表示内容已过时或作废，在文字两边各加两个波浪号 `~~`：

```markdown
~~这是错误的内容，已经被删掉了。~~
```

效果：~~这是错误的内容，已经被删掉了。~~

---

### 四、链接

格式为 `[显示文字](URL)`，中括号写展示文本，小括号写链接地址：

```markdown
[点击访问 Star Blog](https://starblog.totalh.net)
```

**进阶**：给链接加鼠标悬停提示，在小括号里加空格和引号：

```markdown
[我的博客](https://starblog.totalh.net "StarBlog")
```

---

### 五、图片

和链接几乎一样，只在开头多一个感叹号 `!`：

```markdown
![替代文字](https://你的图片链接.jpg)
```

> **为什么要写替代文字？** 图片加载失败时显示这段文字；屏幕阅读器会读给视障用户听。这是基本的无障碍写作素养，别偷懒。

---

### 六、列表

**无序列表**：用 `-`、`+` 或 `*` 加空格开头（推荐统一用 `-`，最通用）。

```markdown
- 苹果
- 香蕉
- 橘子
```

**有序列表**：用数字加点加空格开头。

```markdown
1. 第一步：打开编辑器
2. 第二步：写内容
3. 第三步：发布文章
```

**嵌套列表**：子项前加两个空格或一个 Tab：

```markdown
- 水果
  - 苹果
  - 香蕉
- 蔬菜
  - 白菜
  - 萝卜
```

> **小技巧**：有序列表的序号其实不必严格递增，写成 `1. 2. 3.` 或 `1. 1. 1.` 渲染后都会自动校正。但写成正确序号方便在纯文本模式下阅读。

---

### 七、引用

用 `>` 加空格开头，常用于引用他人言论或突出某段内容：

```markdown
> 这是一段引用内容，可以写多行。
> 每行开头都加大于号。
```

支持嵌套，用两个大于号：

```markdown
> 外层引用
>> 内层引用（嵌套）
```

---

### 八、代码

**行内代码**：用单个反引号包裹，适合在正文中穿插变量名或命令：

```markdown
使用 `console.log()` 可以在控制台输出内容。
```

**代码块**：用三个反引号独占一行，包裹代码内容：

````markdown
```javascript
function sayHello() {
  console.log('Hello World');
}
```
````

> **进阶用法**：在开头的三个反引号后面标注语言名称（如 `javascript`、`python`、`css`），大部分编辑器会自动进行**语法高亮**，代码更易读。

---

### 九、分割线

用三个或以上的 `-`、`*` 或 `_` 独占一行：

```markdown
---
```

效果就是上面那条横线。常用于分隔文章的不同章节。

---

### 十、转义字符

想显示 `*`、`#` 这些符号本身而不被解析成格式？在前面加反斜杠 `\`：

```markdown
\*这是一个星号，不是斜体的开始\*
\#这是一个井号，不是标题的开始\#
```

## 实战：一篇完整的 Markdown 文章

光说不练假把式。下面是一篇用 Markdown 写成的完整短文，**左侧是渲染效果，右侧是源码对照**，帮你直观理解每个语法在实际写作中的运用。

---

### 周末做了一道红烧肉

今天尝试了新菜谱，效果不错，分享给大家。

#### 食材

- 五花肉 500 克
- 冰糖 20 克
- 生抽 3 勺
- 老抽 1 勺
- 八角 2 个

#### 步骤

1. 五花肉切块，冷水下锅焯水去腥
2. 锅里放少许油，加入冰糖炒出糖色
3. 放入五花肉翻炒上色
4. 加入生抽、老抽、八角，加水没过肉面
5. 小火慢炖 40 分钟，大火收汁出锅

出锅撒上葱花，**完美**。

> 这道菜的诀窍在于：炒糖色不能心急，小火慢慢熬，等到冰糖融化成**琥珀色**再放肉，色泽才会红亮诱人。
>
> 古人云：「治大国若烹小鲜。」做菜和做事一样，火候到了，自然成。

*以上就是今天的分享，希望你也能做出好吃的红烧肉。*

## 推荐工具

学会语法后，你需要一个顺手的编辑器来实践。以下三款覆盖不同需求：

| 工具 | 适合人群 | 特点 |
|---|---|---|
| **Typora** | 所有人（强烈推荐） | 所见即所得，极简界面，支持导出 PDF/HTML/Word，全平台 |
| **VS Code** | 程序员 | 装个 Markdown 插件即可，支持预览、格式化、文件管理 |
| **StackEdit / Dillinger** | 不想装软件的用户 | 浏览器打开就能写，写完直接复制到 WordPress |

---

## 写在最后

Markdown 不难，**半小时就能上手**。但一旦习惯它，你会发现再也回不去鼠标点来点去的排版方式了。

**所以，别犹豫了。打开编辑器，用 Markdown 写下你的下一篇文章吧。** 你会发现，写作从未如此顺畅。
